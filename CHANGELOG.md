# Changelog

## 1.8 — 13 November 2026
- Replaced the old accent-colour list and Light/Dark/System choices with two complete themes: Classy (midnight navy and ice white) and Royal (dark chocolate brown, pale gold and metallic gold).
- Applied the selected palette throughout navigation, cards, controls, focus tools and settings.
- Preserved locally stored tasks, notes, habits, goals, focus sessions and preferences while migrating previous colour choices.


## 1.7 — 13 November 2026
- Added a Settings option to permanently delete local tasks, notes, habits, goals, focus sessions and preferences after an explicit confirmation.
- Added a website browser-storage choice banner so visitors can opt out of saving appearance preferences.


## 1.6 — 12 November 2026
- Added a required first-launch legal and liability acknowledgement before app access.
- Added a Legal & Important Information section to Settings for reopening the notice.
- Clarified in-app reminder limitations, critical commitments, local data storage, backups and third-party service dependencies.


## 1.5 — 11 November 2026
- Reworked the main shell with a right-hand navigation rail and a wider left-side content canvas.
- Rebuilt the shell on accent changes so navigation, sidebar links and page controls use the selected theme consistently.
- Removed expensive spotlight bitmap regeneration during window resizing.
- Preserved all locally stored tasks, notes, habits, goals, focus sessions and preferences.


## 1.4.9 — 11 November 2026
- Rebuilt the Windows glass host using colour-key transparency so acrylic can appear behind DayFlow without fading text or controls.
- Expanded the transparency control's tint range and reapply timing.
- Moved the accent-colour nebula spotlight onto the transparent host layer.
- Added a dedicated What's New page with a featured release and previous-version history.
- Preserved tasks, notes, habits, goals, focus sessions and settings.

## 1.4.8 — 11 November 2026
- Added the accent-colour spotlight and persistent Adrian Vale / Ko-fi shortcuts.
- Introduced the initial Windows transparency integration; the backdrop implementation is refined in 1.4.9.

## 1.4.7 — 11 November 2026
- Added persistent creator links to the desktop sidebar.
- Refined accent-colour presentation and retained local-first data storage.

## 1.4.6 — 11 November 2026
- Restored six optional accent choices and refined spacing inside panels.
- Improved Windows application icon assignment for the app window and taskbar.
